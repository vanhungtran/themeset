# List Available Theme Sets

Prints the names of the theme sets available to use with
`apply_theme_set`. The sets that bring their own color and fill scales
come first; the others change only the theme.

## Usage

``` r
list_theme_sets()
```

## Value

A character vector of available theme set names.

## See also

[`list_color_scales()`](https://vanhungtran.github.io/themeset/reference/list_color_scales.md)
for the color scales
