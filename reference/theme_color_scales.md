# Discrete Color and Fill Scales

Convenience wrappers around palette scales from supporting packages.
These functions can be added directly to a `ggplot2` object.

## Usage

``` r
scale_color_npg(...)

scale_fill_npg(...)

scale_color_jama(...)

scale_fill_jama(...)

scale_color_avatar(...)

scale_fill_avatar(...)

scale_color_simpsons(...)

scale_fill_simpsons(...)

scale_color_olink(...)

scale_fill_olink(...)

scale_color_fivethirtyeight(...)

scale_fill_fivethirtyeight(...)
```

## Arguments

- ...:

  Additional arguments passed to the underlying scale function.

## Value

A `ggplot2` scale object.

## See also

[`scale_color_set()`](https://vanhungtran.github.io/themeset/reference/color_scale_sets.md)
and
[`scale_fill_set()`](https://vanhungtran.github.io/themeset/reference/color_scale_sets.md)
to pick any palette by name.
